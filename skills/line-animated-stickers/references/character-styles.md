# Character style choices

This is an optional design catalog, not a claim about which styles are currently
trending. No character name is prescribed.

| No. | Style | Simple explanation |
|---|---|---|
| 1 | 양모 펠트 / 羊毛フェルト風 | Soft wool fibers and a handmade felt-doll finish |
| 2 | 소프트 3D / ソフト3D風 | Rounded, softly shaded three-dimensional character |
| 3 | 손그림 판타지 애니 / 手描きファンタジーアニメ風 | Warm drawn outlines and painted 2D color |
| 4 | 클레이 / クレイアニメ風 | Sculpted clay surfaces with a stop-motion-doll feeling |
| 5 | 픽셀 아트 / ピクセルアート風 | Clear pixel shapes like a retro game character |

| 7 | 뜨개 인형 / あみぐるみ風 | Visible knitted or crocheted yarn texture |
| 8 | 심플 일러스트 / シンプルイラスト風 | Clear bold lines and simple flat colors |

| 10 | 레트로 애니 / レトロアニメ風 | Nostalgic cel-animation outlines and shading |

Offer the choices in the conversation's language and accept another style.
Provide a brief recommendation when useful. If matching examples are available,
show them as examples, clearly distinguished from a preview of the user's own
character. Do not download arbitrary third-party character art as an identity
reference.

When the user asks to compare their own face in several styles, generate a compact
comparison of the requested styles with the same crop, outfit and expression;
label each style. Do not silently generate ten complete character sheets merely
to present a menu. If style is already specified or the user delegates the choice,
proceed without asking again. Keep the selected style consistent across the set.

After a look is accepted, the original prompt's useful sheet layout is 4 columns
by 3 rows: front/45-degree/side/back full-body views; smile/anger/sadness/surprise;
wave/heart/sleepy/joyful pose. Adapt the poses to approved user choices and preserve
the chosen name, colors, clothing and materials. This sheet is an internal identity
reference, not twelve upload-ready LINE stickers.

The old companion prompt ② made 1 or 10 infinitely looping GIFs for sharing in
chat. Do not carry those output settings into this registration workflow. Use the
selected LINE type's counts and PNG (static) or APNG/finite playback (animated) rules from
[registration.md](registration.md).
